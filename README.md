# 💌 How's Your Day? - Web Surat Romantis

Web sederhana berbasis statis (HTML/CSS/JS) yang dibuat khusus untuk menanyakan kabar seseorang dengan cara yang lebih personal dan romantis. Web ini dilengkapi dengan efek animasi ketikan, musik latar, dan integrasi langsung ke WhatsApp.

## ✨ Fitur Utama
- **Typing Effect:** Animasi teks yang muncul seperti sedang diketik secara *real-time*.
- **Floating Hearts Animation:** Efek animasi hati melayang untuk memperkuat tema romantis.
- **Interactive Background Music:** Musik latar otomatis berputar setelah pengguna berinteraksi dengan halaman.
- **Direct WhatsApp Integration:** Pesan yang diketik oleh pengguna akan langsung diteruskan ke WhatsApp pemilik web tanpa melalui database.
- **Responsive Design:** Tampilan rapi dan cantik saat dibuka melalui HP maupun Desktop.

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Untuk struktur halaman.
- **CSS3:** Untuk styling dan animasi (Keyframes).
- **Vanilla JavaScript:** Untuk logika typing effect, animasi hati, dan pengiriman pesan.
- **Google Fonts:** Menggunakan font *Quicksand* dan *Sacramento*.
